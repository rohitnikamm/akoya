# Silk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu bar app for macOS. You hold a key, speak, and let go; Silk transcribes on the Mac and pastes the text into the focused app. The menu bar item shows a live waveform while you speak and a scanning bar while it transcribes. It installs with `brew install --cask rohitnikamm/tap/silk`.

**Architecture:** One SwiftPM package. `SilkCore` is a library holding all logic and UI; it is unit-tested with `swift test`. `Silk` is a thin executable holding `main.swift` and the AppDelegate. `scripts/build-app.sh` assembles and signs `Silk.app`, so Xcode is never needed; the machine has only the Command Line Tools. A `@MainActor` `AppCoordinator` owns the state machine. It talks to hardware only through protocols, so every behavior can be tested with fakes.

**Tech Stack:** Swift 6 (toolchain 6.4), Swift Testing, AppKit (`NSStatusItem`, `NSMenu`), SwiftUI (`Canvas`/`TimelineView`, settings and onboarding), AVFoundation (`AVAudioEngine`, `AVAudioConverter`), CoreGraphics event taps, FluidAudio ≥ 0.12.4 (Parakeet TDT **v2**), ServiceManagement (`SMAppService`), GitHub CLI (`gh`), Homebrew tap.

**Spec:** `docs/superpowers/specs/2026-10-17-silk-design.md` (read it alongside this plan). Approved look: https://claude.ai/artifact/9Ep4HKyADg3Bq9CoFRgSzU

## Global Constraints

- Apple Silicon only, macOS 14+ (`platforms: [.macOS(.v14)]`, `LSMinimumSystemVersion` 14.0).
- Bundle id `com.rohitnikamm.silk`. App name `Silk`. Status item `autosaveName` `"SilkStatusItem"`.
- `LSUIElement` = true (no Dock icon). The app never takes key focus during dictation.
- No network access except the one-time model download. Audio never leaves the device.
- Models live in `~/Library/Application Support/Silk/Models`.
- Menu bar geometry: idle item 28 pt; active item 77 pt (22 columns × 2 pt + 21 × 1 pt gap + 6 pt padding on each side); tallest column 20 pt.
- Scanner: 700 ms per end-to-end sweep (1.4 s period), ease-in-out-sine; brightness 1.0 / 0.7 / 0.48 / 0.32, unlit 0.18.
- Hold shorter than 0.25 s → cancel. Esc while recording → cancel (and Esc is swallowed). Recording auto-stops at 5 min. *(The 5-minute cap is the plan's call.)*
- Inserted text = transcript trimmed of whitespace, plus one trailing space. *(Plan's call: back-to-back dictations don't run together.)*
- Hotkeys: Right Option (default), Right Command, Right Control. Modes: hold (default), toggle.
- Releases are not notarized. Signed with the self-signed identity `"Silk Self-Signed"` (falls back to ad-hoc `-` if it's missing). The cask strips quarantine in `postflight`.
- Tests use Swift Testing (`import Testing`, `@Test`, `#expect`). XCTest is unavailable without Xcode.

## Review Focus

1. **The key-up event is missed** (app beach-balls, or the tap is disabled by timeout). Silk must not stay stuck recording. Expected: any later `flagsChanged` that shows the hotkey's modifier not held counts as a release, and a disabled tap is re-enabled. Tests in Task 6.
2. **The clipboard holds non-text** (an image, copied Finder files, rich text). Expected: every type is restored exactly. If the user copies something during the 300 ms window, their copy wins. Tests in Task 8.
3. **Microphone permission is denied, or no input device exists.** Expected: pressing the key shows the error cue and returns to idle, with no crash and no stuck waveform. Test in Task 5 (the fake audio throws on `start()`).
4. **The input device changes mid-recording** (AirPods connect or disconnect). Expected: recording stops and whatever was captured is transcribed. Test in Task 7 (the configuration-change handler calls `onInterrupted`). Task 5 covers the coordinator side.
5. **A secure input field is focused** (a password box, or Terminal with Secure Keyboard Entry), so the tap receives no keys. Expected: nothing happens and nothing is left in a bad state. Covered by the "release without press is ignored" test in Task 5, plus a manual check in Task 11.
