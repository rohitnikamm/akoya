Keeping it simple

  • One short instruction per screen: "Say something. Pick the one that moves."
  • Plain names only ("This PC's microphone", "Webcam mic", "Galaxy Buds"). Windows' technical names never appear in setup.
  • Virtual and loopback devices (NVIDIA Broadcast, Stereo Mix) sit behind "More", so most people see 2–3 rows.
  • In the usual case nothing needs choosing: you talk, see "Hearing you", press Continue. With one mic it’s the same screen with one row.

Rules underneath

  • One mic is always highlighted: the Windows default. Akoya never switches it on its own. If the highlighted mic hears nothing, the status turns amber ("Galaxy Buds isn't hearing you") and you click the row that moves.
  • Your pick is saved as that device, so Discord or Voicemeeter changing the Windows default won't move it. The tray panel keeps the Mac's "System default" option for anyone who wants to follow Windows.
