Option A trade-off

Fewer screens. You confirm the mic by dictating, so a wrong default shows up as "Didn't catch that, try again", and you then switch mics in the line under the card.

Option B trade-off

One extra screen, a few seconds long. You see which input hears you before the hotkey is involved, so Try it works first time. It catches webcam mics, "Stereo Mix" and virtual devices (Discord, NVIDIA Broadcast, Voicemeeter) being the Windows default.
