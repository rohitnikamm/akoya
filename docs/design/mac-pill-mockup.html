The pill on the Mac

The Windows pill, brought over as it is: same look, same 34 pt height, same live dot waveform and timer, same jelly pop-in and the same messages. It becomes the Mac's default way to show dictation; the menu bar waveform stays available as an option. Everything below is at real size.

1. Where it sits

Centred above the Dock on the screen holding the window you're typing into. It never takes focus, clicks pass through it, and it shows on every Space and over full-screen apps. While the pill is showing, the menu bar item stays the plain idle glyph (no second waveform).
